DOMGuard Privacy Policy

DOMGuard processes page content and screenshots in your browser. It does not upload them to any server.

DOMGuard does not save page content or screenshots. A sensitive-data scan keeps only the type and the position on the page, not the matched text.

Hidden-text detection shows, in the extension popup, a preview of at most 80 characters of the detected text for each item. Those previews exist only in memory while the popup is open. They disappear when the popup closes. They are not saved, and they are not sent outside the browser.

A screenshot is turned into a downloaded file from the popup. It is not written to the extension’s storage.

Payments

The only network communication is with ExtensionPay (extensionpay.com). It is used for Pro payment and for checking whether this install is paid. ExtensionPay and Stripe handle the payment. DOMGuard does not handle credit card information.

ExtensionPay saves a user record (including email and payment status), an API key, and the install time in the browser’s chrome.storage.sync. This is ExtensionPay’s own behavior. For information about its privacy, see extensionpay.com.

Saved on this device

DOMGuard saves the day’s free-screenshot count in chrome.storage.local. That record is a date and a count. Pro status is cached in memory only and is not written to disk.

Permissions

  • activeTab — work on the tab where you opened DOMGuard, including a screenshot of the visible area.
  • scripting — inject DOMGuard’s script into that tab.
  • storage — save the day’s free-screenshot count, and let ExtensionPay save its entitlement record.
  • extensionpay.com — reach ExtensionPay for payment and Pro checks.
